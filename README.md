# Доработка скрипта диагностики: Сверка с эталонными списками ПО

### 1. Состав базового рабочего ПО (Белый список)
* **Офисный софт (LibreOffice / МойОфис)**: База для работы с таблицами, договорами и текстами.
* **Архиватор (7-Zip)**: Необходим для безопасного извлечения вложений из рабочих писем.
* **PDF-ридер (Foxit / SumatraPDF)**: Инструмент для просмотра счетов и актов.
* **Браузер (Chrome / Яндекс)**: Обязателен для доступа к внутренним веб-системам.
* **Антивирус**: Контур базовой безопасности хоста.

### 2. Признаки излишнего / нецелевого ПО (Черный список)
* **Игровые платформы (Steam / Epic Games)**: Отвлекающий фактор, нецелевое расходование диска.
* **Торренты (qBittorrent / uTorrent)**: Риск перегрузки каналов связи и загрузки вредоносных модулей.
* **Мессенджеры (Telegram / Discord)**: Потенциальный источник утечки корпоративной информации. Требуют верификации ИТ-отделом.
* **Стриминг и кастомизация (OBS / Wallpaper Engine)**: Нецелевая нагрузка на графическую систему ПК.

### 3. Метод тестирования логики
* **Проверка дефицита**: Из условий поиска `findstr` временно убирался маркер `7-Zip`. Скрипт корректно реагировал и выдавал рекомендацию к установке архиватора.
* **Проверка профицита**: В массив данных искусственно добавлялись строки `Steam` и `Telegram`. Скрипт успешно детектировал их и переносил в Раздел 3 отчета.
